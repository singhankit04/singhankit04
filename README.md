## 📌 Featured Projects

### [Obliq — Multi-Tenant Workspace & Project Management Platform](https://github.com/singhankit04/Obliq)

A full-stack project management platform with a service-layered REST API, real-time notifications, and production-grade auth.

- **35+ REST endpoints** across Workspaces, Projects, Tasks, and Comments with cascading CRUD
- **Dual-token JWT auth** with refresh token rotation, Google OAuth 2.0, and token-reuse detection
- **Redis-backed sessions** (HSET/HGETALL) with sliding-window rate limiting via atomic transactions
- **BullMQ email pipeline** for welcome, invite, and @mention notifications + **Socket.IO** real-time delivery
- **Dockerized** and deployed on Render with RBAC (Owner, Manager, Member)

`Node.js` `Express` `MongoDB` `Redis` `BullMQ` `Socket.IO` `Docker` `React` `Zod`
